# Tamoor Munawar — Portfolio

One-page portfolio site: full-stack engineer for KYC, AML and fintech products.
Plain HTML, CSS and a little JavaScript. No build step.

## Run locally
Open `index.html` in a browser.

## Edit
- Text, colors and fonts: search `index.html` for `EDIT:` comments and the `:root` block.
- Images live in `images/` (1600 x 900 px, `.webp` or `.jpg`).
- Contact form: replace `YOUR_FORM_ID` in the form's `action` with your Formspree form ID.

## Deploy with GitHub Pages
Repo **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.
The site will be live at `https://tamoormunawar.github.io/portfolio-tamoor/`.
